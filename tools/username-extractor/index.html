TikTok Campaign Username Extractor

Get every display name and @username from a TikTok LIVE campaign leaderboard, sorted by score. Use the one-click bookmark below, or paste data copied from your browser’s Network tab. Runs entirely in your browser.

One-click grab from a TikTok campaign page

Where the usernames come from: the leaderboard of a TikTok LIVE campaign / event page on tiktok.com that you have open in your own browser and are logged into, e.g. the ranking tabs of a campaign (Star Legend, Rising Star, Star Seeker…).

What it reads: only the leaderboard data that page loads: display name, @username, rank and score of the creators listed on it. If no leaderboard data has loaded, it falls back to the @profile links visible on the page.

What it doesn't do: it runs only when you click it, only on the tab you're viewing. It doesn't read cookies, passwords, messages or anything outside that leaderboard, and sends nothing to any server. The data goes straight from your TikTok tab to this page in your browser.

  1. Install once: drag this button to your bookmarks bar → Grab usernames (On a phone or if dragging doesn't work: , create any bookmark, and paste it as the bookmark's URL.)
  2. Open the campaign page on tiktok.com while logged in.
  3. Click the "Grab usernames" bookmark. A small panel appears. Click through each leaderboard tab and scroll to the bottom so every rank loads; the count goes up as data arrives.
  4. Click "Open in extractor". This page opens with the data loaded and the usernames extracted.

Only use it on campaigns you take part in or manage, and in line with TikTok's terms. If TikTok changes its page and nothing is found, use the manual method below.

Manual method: copy the data from the Network tab
  1. Open the campaign page while logged in, press F12, open the Network tab, filter by Fetch/XHR.
  2. Click through each tab (Star Legend, Rising Star, Star Seeker). Scroll each to the bottom so every "load more" request fires.
  3. For each request that returns rankings: right-click → Copy → Copy response, paste below. Stack all three tabs' responses in the box — they're all read and combined into one list.
  4. Or right-click the Network list → Save all as HAR, open the file, paste its contents here. HAR is detected automatically.
